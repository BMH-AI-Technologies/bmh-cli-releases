# ✦ bmh

Trợ lý làm việc văn phòng của BMH, chạy ngay trong Terminal hoặc Antigravity.
Repo này chỉ chứa bản cài đặt. Bạn cần **mã mời** do quản trị viên BMH gửi.

## Cài đặt

**macOS**, dán vào Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/BMH-AI-Technologies/bmh-cli-releases/main/install.sh | BMH_INVITE=BMH-XXXX-XXXX sh
```

**Windows**, dán vào PowerShell:

```powershell
$env:BMH_INVITE="BMH-XXXX-XXXX"; irm https://raw.githubusercontent.com/BMH-AI-Technologies/bmh-cli-releases/main/install.ps1 | iex
```

Thay `BMH-XXXX-XXXX` bằng mã mời của bạn. Trình cài đặt sẽ hướng dẫn đăng nhập ChatGPT hoặc GitHub Copilot (dùng gói của chính bạn).

## Sử dụng

Mở thư mục làm việc, gõ `bmh`, rồi nói việc cần làm bằng tiếng Việt.
Cập nhật: `bmh update` · Hướng dẫn: `bmh help`

Hoạt động trong bmh được ghi lại cho tổ chức của bạn; bmh luôn hiện dấu ● khi đang ghi.
